# Retail Sales Data Dashboard — Project Report

## Introduction
This project analyzes retail transaction data to produce management-oriented insights through data cleaning, KPI analysis, visualization and recommendations.

## Objectives
Analyze sales trends, product/category performance, regional performance, customer segments and profitability.

## Methodology
Data collection → cleaning → duplicate/missing-value handling → date transformation → KPI calculation → SQL analysis → Power BI visualization → business validation → recommendations.

## Key Reference Results
The standard Superstore dataset contains 9,994 transactions, approximately $2.297M sales, approximately $286.4K profit and 37,873 units.

## Findings
Technology is the strongest category by sales and profit in the standard dataset. West leads the regions in sales and profit. Some products/sub-categories are loss-making, so discount and profitability analysis is important.

## Recommendations
Focus on high-margin products, investigate loss-making items, review discount levels, monitor regional trends and use segment-level insights for targeted campaigns.

## Limitations
This is an educational dataset and does not represent current company data. Observed relationships should not automatically be interpreted as causal.

## Conclusion
The project demonstrates an end-to-end retail analytics workflow from raw transactions to dashboard-based business recommendations.
