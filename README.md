# Data Analytics Projects

Welcome to my Data Analytics portfolio repository.

This repository contains practical data analytics and machine learning projects demonstrating skills in data analysis, visualization, Python, machine learning, and business intelligence.

## Projects

### 1.Predictive Analytics – Stock Market

A machine learning project that uses historical Apple (AAPL) stock-price data to predict the next closing price.

**Technologies:**
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Random Forest Regression

**Key Features:**
- Historical stock-price analysis
- Feature engineering using previous closing prices
- 5-day and 10-day rolling averages
- Random Forest Regression model
- Model evaluation using MAE, RMSE, and R² Score
- Data visualization

**Project Folder:**
`2_Predictive_Analytics_Stock_Market`

### 2.Retail Sales Data Dashboard

A Power BI dashboard project designed to analyze retail sales data and provide useful business insights.

**Tools:**
- Microsoft Power BI
- Power Query
- Data Visualization
- Data Analysis

**Key Features:**
- Sales performance analysis
- Revenue and sales trends
- Product/category analysis
- Interactive dashboard
- Business-focused visualizations and insights

`Retail_Sales_Data_Dashboard`
