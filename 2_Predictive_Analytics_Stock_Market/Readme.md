#  Predictive Analytics Stock Market

## Project Overview

This project analyzes historical Apple (AAPL) stock market data and uses
machine learning to predict the next day's closing price.

The project demonstrates data analysis, feature engineering,
visualization, and predictive modeling using Python.

##  Objectives

- Analyze historical AAPL stock prices
- Explore stock price trends
- Create predictive features using historical prices
- Build a machine learning regression model
- Evaluate model performance
- Compare actual and predicted prices

##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
- GitHub

##  Machine Learning

A Random Forest Regression model is used to predict the next closing price.

## Features

- Previous day's closing price
- Previous 2-day closing price
- Previous 3-day closing price
- Previous 5-day closing price
- 5-day rolling average
- 10-day rolling average

## Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Notebook
The complete analysis and machine learning workflow is available in:`notebooks/AAPL_stock_prediction.ipynb`
